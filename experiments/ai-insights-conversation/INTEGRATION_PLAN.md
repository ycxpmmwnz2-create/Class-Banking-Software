# Isolated integration test — September 6, 2026

Andrew authorized “do the iso test” after Muse round 15. This next slice imports the real structured assistant, question service, cost policy and usage ledger into an experiment-only composition. No production entrypoint, client, Firebase configuration, rules, data, or deployment changes.

Scope: new local integration module, tests, fictional provider runner and preview under this experiment directory. Four fictional students and the existing explicit August 31–September 6 comparison are the first supported scenario; this is not the production full-roster implementation. Every generated paragraph is an AI draft for human semantic review and is displayed separately from a short server-calculated summary. The production `structured-v1` result remains intact and is not relabelled to contain free prose.

The normal question service handles the planner, executed tools, structured selection, reservation, persistence and replay. The experimental wrapper verifies the selected operation/filter/date/population against the supported comparison before narrating. It reserves narration separately with a distinct request ID derived from the caller request; the real ledger binds it to teacher/classroom and a digest of the completed base answer, current evidence and fact packet. One narration attempt, 30 seconds, no retries. Successful/fallback preview is persisted for identical replay. Missing or invalid usage retains the full narration reservation as a conservative charge; this preview explicitly records that it is reserved-unknown rather than observed billing. Budget exhaustion must preserve the valid calculated answer. A future production design should account for narration in the original request's reservation/rate limit rather than doubling hourly request consumption.

Factual guarantees stop at the calculated summary. Free prose may still be wrong; neither JSON checks nor the narrow selection check certifies it. No generated paragraph is served as the production answer. This local preview is for evaluation only.

Fixes tested: explicit warning before any ranking when full history/complete results are missing; earnings summary/details exclude account balance and frozen-state data. Preserve the conservative first-day history check for this fixed-date slice; full timezone/DST coverage is still a later production requirement.

Acceptance: real question-service and ledger path with injected provider on in-memory Firestore semantics; identical request/body returns byte-equivalent preview and adds zero provider calls/charge; two tenants stay distinct; unknown scope and stale evidence cannot acquire a plausible narration; malformed/timeout/unknown-usage/budget refusal preserve the verified summary; concurrent identical calls never duplicate provider work; only usage collection writes; no bank records changed. Test files and saved results distinguish fake provider/unit evidence from real Gemini runs and local browser checks.
