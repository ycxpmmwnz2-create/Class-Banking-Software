# Conversational-answer experiment

Authorized September 6, 2026: Andrew agreed to try Gemini wording from verified facts, preserving the working calculation system. Codex implements this isolated experiment; Muse remains the independent reviewer, operated by Andrew. Baseline 6aa2e3a has the same tree as released merge 8b2b4da. Branch: codex/ai-insights-conversational-experiment.

Objective: measure whether Gemini can give a short, friendly explanation of known classroom results without changing their meaning. Start with most/least approved money added in a fixed date range, including ties and zero-earners. This is an offline preview plus bounded real-provider experiment; it is not wired into the app, callable, cache, or usage ledger.

Scope: new files beneath experiments/ai-insights-conversation only. Existing tools calculate synthetic results; an experiment adapter constructs a fact packet. Gemini receives the fixed fictional question and packet, no tools or real classroom data. No changes to existing code, production/staging deployments, Firestore, rules, gates, credentials, or model configuration.

Acceptance: independently asserted known results for unique extremes, tied extremes, all-zero activity, empty roster, truncated results, incomplete history, credits versus net balances, and unsupported judgments. Missing coverage cannot become a classwide winner. Names, dollar amounts, population, dates and ties must agree with facts; no attribution of effort, motivation or causes. Format success is not semantic proof. All model prose remains a review candidate, never automatically approved. Errors preserve the original deterministic answer. A test deliberately supplies false but syntactically valid prose and proves it cannot become a serving answer.

Provider run: existing gemini-3.6-flash transport, staging secret binding version 1 held only in memory, one attempt per case, 30 second request deadline, no SDK/outer retries. Eight fixed cases, run once, conservative reservation before each call. Carry forward USD 0.954175 against original USD 2 ceiling; new experiment cap USD 0.50. Save unknown-usage reservations rather than assuming no charge. No secret/raw error logging. Preserve prompts, fictional facts, raw answer text, usage and case status for manual semantic review. No network during --check or unit tests.

Tests: existing npm --prefix functions test invocation narrowed to structuredClassroomAnswers.test.js and classroomAssistantTools.test.js; Node --test for new experiment tests; ESLint for new files; git diff --check. Local tests prove the adapter/fallback, not Gemini reliability. Real-provider responses require separate meaning/tone assessment and must not be labelled production verified. Any later production integration needs a bounded review of provider budgets, fallback, cache/replay persistence, tenant isolation and UI before release.

## Prompt revision after first run

The first eight real-provider answers preserved the ranking values but remained overly formal. One response blurred an incomplete returned page into incomplete records; one omitted currency symbols. Round 1 is preserved, including source files and exact requests. Round 2 keeps the fixtures/calculations and changes narration instructions: 65-word conversational paragraph, USD explicit, fixed scope/date/definition shown separately, and an explicit distinction between truncated results and missing history. Carry USD 0.965298 into the original USD 2 ceiling and leave USD 0.488877 of the new experiment's USD 0.50 cap. This is a justified changed-prompt trial, not a retry of a failed provider operation or completed review.
